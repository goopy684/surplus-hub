# MaterialCard
홈·관심 목록의 사진 중심 자재 카드. 모바일 2열(gap 12/24), 웹 3열.

- 썸네일: `aspect-square rounded-thumb bg-field`, 사진 `object-cover`, 없으면 이미지 아이콘 `ink-3`.
- 좌상단 배지: 예약중(흰 필), 등급(상 = olive 필, 중·하 = line 아웃라인). 값이 없으면 렌더하지 않는다.
- 판매완료: 썸네일 위 `bg-ink/60` + 흰 12/700, 제목·가격 `ink-2`.
- 정보: 제목 14/600 2줄 → 가격 `num` 17/700 + 원 13/600 → 메타 12 `ink-2` → (수량 · 관심 n).
- 무료나눔은 가격 자리에 `primary` 800.
- 카드 전체가 하나의 `<a>`. 그림자·보더 없음.
