# Badge
상태·등급·카테고리 라벨. 색은 의미가 있을 때만, 값이 없으면 렌더하지 않는다.

- 판매중: `bg-accent text-accent-foreground` 필.
- 예약중: 사진 위 흰 필 / 텍스트 영역 `bg-field text-ink-2`.
- 등급 상: `bg-olive-bg text-olive-tx border-olive-bd`. 중·하: `border-line bg-surface text-ink-2`.
- 커뮤니티 카테고리: 배경 없이 `text-primary` 12.5/700.
- 미읽음: `bg-primary` 8px 점 또는 숫자 필.
- 11.5–12.5 / 700, `rounded-chip`.
