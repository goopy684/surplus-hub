# FilterChip
목록을 거르는 필 칩 레일. 선택은 잉크 채움 — 코발트가 아니다.

- 높이 38, `px-4 rounded-chip border`, 라벨 14.
- 비활성: `border-line bg-surface text-ink font-medium`, hover `bg-field`.
- 활성: `border-ink bg-ink text-surface font-bold`, `aria-pressed` 또는 `aria-current`.
- "전체" 칩을 맨 앞에 두어 해제 가능하게. 가로 스크롤은 `scrollbar-hide`.
- 아이콘은 넣지 않는다.
