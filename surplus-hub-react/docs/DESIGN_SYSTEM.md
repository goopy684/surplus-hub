> ⚠️ **색·폰트 토큰의 정본은 이 문서가 아니다.**

> 이 문서는 **컴포넌트·레이아웃·보이스 상세 스펙(§2~§9)** 만 담당한다. 색 값이 필요하면 위 두 파일을 본다.

> 건설 잉여자재 중고거래 마켓플레이스 "자투리"의 화면 스펙.

## 0. 디자인 원칙 (왜 이렇게 생겼나)

1. **따뜻한 동네거래 (Warm & local).** 차가운 기업용이 아니라, 동네에서 믿고 거래하는 따뜻함. 종이 같은 웜 뉴트럴 배경 + 단일 웜 악센트.
2. **절제 = 위계 (Restraint is hierarchy).** 강조색은 **단 하나**(현행 `--accent`). 화면마다 "가장 중요한 액션 1개"에만 쓴다. 색이 하나여야 그 색이 신호가 된다.
3. **가독성 우선 (Readability first).** 주 사용자는 **50대 현장 종사자**, 종종 야외·햇빛 아래. 본문은 AA 대비 이상, 가격·제목은 큼직하게. 단 "효도폰"처럼 글자만 키우지 않고 위계·여백으로 균형.
4. **정보 위계는 정체성 (Info is identity).** 이 서비스의 차별 정보 = **등급(상/중/하) · 수량/규격 · 거리(km) · 시간**. 어떤 화면에서도 이 4가지는 또렷하게.
5. **기능 > 장식 (Function over decoration).** 찜·시간·상태(예약중/거래중)·사진수는 "장식"이 아니라 "신뢰". 그라데이션 히어로·컬러 배지 남발 같은 장식은 금지(§9).

## 1. 컬러 토큰 — 이 문서에 없음

**색상 정본은 루트 [`design.md`](../design.md) + `apps/web/src/app/globals.css`의 `:root`다.**
`apps/web/tailwind.config.js`가 그 값을 미러링하며, 값을 바꿀 땐 세 파일을 함께 고친다.

이 문서에 있던 테라코타 팔레트(hex 표 + Tailwind 매핑)는 폐기됐다. 아래 스펙에 나오는 `--paper` / `--ink` / `--accent` 같은 이름은 **정본에 정의된 토큰을 가리키는 참조**이지, 여기에 값이 있다는 뜻이 아니다.

**hex를 직접 쓰지 말고 토큰 클래스만 사용한다** (`bg-paper` `text-ink` `bg-primary` `rounded-thumb` 등).

색 사용 규칙(악센트는 화면당 주요 액션 1곳·5% 이내, 두 번째 강조색 금지, 등급 색 규칙, 명도 위계 3단)은 `design.md`에 정리돼 있다.

## 2. 타이포그래피

- **서체**: `Pretendard` (CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.css`), 폴백 `-apple-system, 'Apple SD Gothic Neo', system-ui, sans-serif`.
- **숫자**: 가격·수량·거리·규격은 `font-variant-numeric: tabular-nums` (세로 정렬·흔들림 방지). 천단위 콤마.
- **한글 자간 사다리**: 18px+ = `-0.4px` · 16~17px = `-0.2~-0.3px` · 12~13px = `-0.1px` · 작은 라벨 = `0`.

| 역할 | size / weight / line-height / letter-spacing | 색 |
|---|---|---|
| Hero price (상세) | 26 / 700 / 1.1 / -0.5 | `--ink` |
| Screen title · Section h2 | 19 / 700 / 1.2 / -0.4 | `--ink` |
| Card title (제목) | 17 / 600 / 1.32 / -0.3 | `--ink` |
| **Feed price (가격)** | 20 / 700 / 1.1 / -0.5 · tabular | `--ink` |
| Body / spec (스펙·설명) | 13.5 / 500 / 1.5~1.6 / -0.1 | `--ink-2` |
| Meta (거리·시간) | 12.5~13 / 500 / 1.3 / -0.1 · tabular | `--ink-2` |
| Price unit (원, /장) | 13 / 500~600 | 원=`--ink-2`, /단위=`--ink-2` |
| Chip label (등급·상태) | 12 / 600~700 | 칩별 |
| Tab label | 12 / 500 (활성 600) | `--ink-2` / `--ink` |
| Caption (placeholder·time stamp) | 12 / 400~500 | `--ink-3` |
| Status bar | 15 / 600 (SF Pro) | `--ink` |

> 가격이 항상 행의 시선 종착점. 가격 정수부가 "주인공", 통화/단위는 한 단계 죽인다.

## 3. 스페이싱 · 레이아웃 · 형태

- **그리드**: 4/8 기준. 화면 좌우 패딩 = **20px** (헤더·검색·섹션·피드 모두 동일 축).
- **간격 스케일**: 6 · 8 · 14 · 16 · 20 (px). 카드 내부 행간 4/8.
- **모서리 반경(radius)**: 칩 6 · 입력/검색 12~13 · 카드 썸네일 14 · 카테고리 아이콘 16 · 버튼/FAB 16~17.
- **프레임**(시안 목업 전용): 390 × 844, 중앙 정렬. 실제 앱에는 프레임 배경·드롭섀도가 없다.
- **세이프에어리어 (iOS)**: 상태바 `54px` · 하단 탭바 `84px`(하단 인셋 ~34 포함) · 홈 인디케이터 `134×5, opacity .2`.
- **터치 타깃**: 최소 44pt. 검색바 50px, 카테고리 아이콘 54px, 버튼 높이 52~56px.
- **그림자**: 절제. 카드엔 헤어라인(`--line-2`)으로 구분, 그림자 X. 떠야 하는 요소(FAB)만 부드럽게 — 색은 악센트 토큰 기준으로 낮은 알파를 쓴다.

## 4. 아이콘
- **모노라인 SVG만.** stroke-width 1.8~2.0, 24px viewBox. 이모지·컬러 아이콘·외부 이미지 금지.

## 5. 컴포넌트

각 컴포넌트는 §1~4 토큰으로만 구성한다.

### 5.1 상태바 (Status bar)
9:41 + 신호/와이파이/배터리(SVG). height 54, padding `14px 20px 0`, 15/600, SF Pro. 모든 화면 상단에 동일 복붙.

### 5.2 상단 내비바 (App bar)
- **홈형**: 위치 선택(핀 `--accent` + 19/700 + chevron `--ink-2`) 좌측, 알림 벨(점 배지 `--accent`) 우측.
- **푸시형**: 뒤로(←) 좌측, 제목 19/700 가운데(또는 좌측), 액션 아이콘 우측. (상세는 이미지 위 반투명 오버레이 가능)

### 5.3 하단 탭바 (Tab bar)
5탭: 홈 · 검색 · **등록(중앙 FAB)** · 채팅 · 내정보. height 84, 상단 `--line`. 비활성 `--ink-2`/12/500, 활성 `--ink`/600 + 아이콘 `--accent`. 중앙 FAB: 54px, radius 17, `--accent` 배경, 흰 +.
> 푸시된 화면(상세·등록·채팅)은 탭바 대신 하단 액션바/입력바. 검색은 탭 유지 가능.

### 5.4 검색바
`--field` 배경, radius 12~13, height 50, 좌측 돋보기(18~19), 입력 16~17/500, placeholder `--ink-3`.

### 5.5 카테고리 칩 레일
가로 스크롤. 칩 = 아이콘 컨테이너(54×54, radius 16, `--surface`+`--line`) + 라벨(13/500/`--ink-2`). **활성** = `--accent-soft` 배경 + 아이콘 `--accent` + 라벨 `--ink`/600(테두리 제거). 우측 끝 페이드 마스크로 스크롤 암시.

### 5.6 자재 카드 (피드/검색 결과 공통)
가로 레이아웃: 썸네일(80~84, radius 14) + 메타. 구분선은 `--line-2` 헤어라인이며 **썸네일 아래로 지나가지 않게**(left inset ≈ 98px). `align-items: flex-start`.
- 썸네일: 실사진, 없으면 `--field` 단색 플레이스홀더(§6) + `찜 하트`(우상단 26, 반투명 다크 배경) + `사진수`(좌하단 pill).
- 메타: row1(등급칩 + 시간/상태) → 제목(17/600) → 스펙(13.5/`--ink-2`, `수량 · 규격`) → row2(가격 좌 / 거리 우, baseline 정렬).

### 5.7 등급 · 상태 칩
- **등급 "상"**: `--olive-tx`/`--olive-bg`/`--olive-bd`. **"중"·"하"**: `--surface`/`--line`/`--ink-2`(무채 아웃라인). **등급 값이 없으면 칩을 렌더하지 않는다.**
- 상태칩(예약중) : `--field` 배경 + `--ink-2`(중립 칩). **거래중**: `--accent` 점 + 텍스트(컨텍스트 바에서). **무료나눔**: 가격 자리에 `--ink`/700(악센트 아님).
- 모든 칩: 12/600~700, padding `2px 8px`, radius 6.

### 5.8 가격 표기
`<b>320,000</b><span class="won">원</span><span class="unit">/장</span>` — 정수부 20/700 `--ink` tabular, `원`·`/장`은 13/500 `--ink-2`. 무료나눔은 `--ink`/700.

### 5.9 메타 (거리·시간)
거리 = 핀(12~13) + `지역 · n.nkm` (`--ink-2`, tabular). 시간 = `끌올 10분 전`/`2시간 전`/`어제` (`--ink-2`/12.5).

### 5.10 버튼
- **Primary**: `--accent` 배경, 흰 텍스트 16~17/700, radius 14~16, height 52~56. (채팅하기/등록하기/전송)
- **Secondary/icon**: 아웃라인(`--line`) 또는 무배경, `--ink`.
- 화면당 Primary는 하나.

### 5.11 입력 필드 / 세그먼트 (등록 폼)
- 라벨 13/`--ink-2` 위, 입력 `--field` 배경 radius 12, height 52, 글자 16~17. select 행은 우측 chevron.
- 세그먼트(등급 상/중/하): 활성 칸 `--surface`+그림자/`--olive` 강조, 비활성 `--ink-2`.
- 토글/체크(무료나눔): 체크 시 `--accent`.

### 5.12 채팅
- 받은 버블: `--surface`(또는 뉴트럴) 좌측. 보낸 버블: **`--accent-soft` 웜톤** 우측(진한 악센트 금지 — 화면 절반이 악센트가 되면 안 됨). radius 16~18, 시간 `--ink-3`/12.
- 거래 컨텍스트 바: `--field` 배경 + 썸네일 + 제목 + 가격 + `거래중`.
- 입력바: + (사진) / 둥근 입력필드 / 전송(텍스트 있을 때 `--accent`).

### 5.13 매너온도
올리브 톤(`--olive-tx`) + 온도계 아이콘 + `36.5°C`. 신뢰 지표로 판매자/채팅 헤더에.

## 6. 제품 이미지 플레이스홀더

사진이 없을 때는 `--field` **단색** 배경 + `--line-2` 보더로 처리한다. 컬러풀 일러스트·이모지 금지.

> 구 v3의 자재별 듀오톤 그라데이션 스펙(`.t-steel` / `.t-ply` / `.t-insul` / `.t-tile`)은 폐기했다.
> 현행 시스템은 **그라데이션 전면 금지**이며(`design.md` → Motion stance), 해당 클래스는 코드에도 존재하지 않는다.

## 7. 콘텐츠 · 보이스
- 언어: 한국어. 간결·정중·현장 친화("직접 보고 가져가실 분 환영합니다").
- 단위: `원`, `/장`·`/박스`, `톤`·`장`·`박스`(수량), `km`(소문자), `°C`.
- 숫자: 천단위 콤마, 규격은 `1,220 × 2,440`(× 양옆 공백).
- 등급: `상`/`중`/`하` (등록 폼 라벨은 `상 (양호)` 형태). 상태: `판매중/예약중/거래중/거래완료`. 무료: `무료나눔`.

## 8. 접근성
- 본문/보조 텍스트 대비 ≥ **4.5:1**(WCAG AA). `--ink-2`(≈6:1) 이상 사용, `--ink-3`는 비필수 텍스트만.
- 터치 타깃 ≥ 44pt. 50대 가독성: 핵심 정보(제목·가격)는 큼직하게, 색 대비를 크기보다 먼저 확보.
- 색만으로 정보 전달 금지(등급은 색+텍스트 라벨 병기).

---

## 9. 하지 말 것 (Anti-patterns) ⚠️
- ❌ 두 번째 강조색 추가(블루/그린 등). 악센트는 `--accent` 하나.
- ❌ **그라데이션 전면 금지** — 히어로 배너·프로모션 카드·버튼·FAB 모두 단색.
- ❌ 카드에 그림자/네온 글로우 추가, 과한 라운드.
- ❌ 이모지 아이콘, 컬러 배지 남발.
- ❌ 가격·일반 요소에 악센트 도배(희소성 파괴).
- ❌ 임의 hex/rgb 인라인. 토큰 클래스만 쓴다.
- ❌ "효도폰"식 거대 폰트 — 크기보다 대비·위계로 가독성 확보.
- ❌ 폰트 패밀리 교체·세리프 혼용, 한 화면 weight 5종 이상.

## 10. 구현용 토큰 — 이 문서에 없음

복붙용 값은 여기서 관리하지 않는다. 정본 파일에서 직접 가져온다.

| 형태 | 파일 |
|---|---|
| CSS 변수 (정본) | `apps/web/src/app/globals.css` → `:root` |
| Tailwind 매핑 (미러) | `apps/web/tailwind.config.js` |
| 시스템 규칙·요약 | 루트 [`design.md`](../design.md) |
| 모바일 | `apps/mobile/tailwind.config.js` + `apps/mobile/global.css` (NativeWind) |

값을 바꿀 땐 `design.md`를 먼저 고치고 globals.css / tailwind.config.js에 반영한다.
